# InSAR Studio 新手指南

这是一份写给第一次接触 InSAR、第一次用命令行、第一次跑形变处理的人的指南。它不假设你会 SNAP、ISCE 或 Gamma，也不假设你知道什么是解缠相位。你只需要会解压文件、双击图标、在浏览器里点按钮。

读完并跟着做，你会完成三件事：

1. 在自己的电脑上启动 InSAR Studio；
2. 跑通一个不需要任何外部数据的演示项目；
3. 用仓库里已经准备好的真实案例，得到一张同震形变图和一张滑坡速率图。

整个过程不需要 GPU，不需要服务器，不需要注册数据账号。真实原始 SLC 的下载和处理是另一条路，文末会说明。

## 0. 先用一分钟认识它

InSAR Studio 是一个**本地运行**的 InSAR 形变处理工作台。它把下面这条链路串起来：

```text
数据接入 → 配准 → 干涉网络 → 差分干涉 → 大气校正 → 时序反演 → 成果输出
```

它支持四条路线：

| 路线 | 一句话解释 | 最少景数 |
| --- | --- | ---: |
| **D-InSAR** | 两景之间做一次差分，看一次地震、滑坡或沉降 | 2 |
| **SBAS-InSAR** | 多景小基线组合，得到时间序列和年均速率 | 8 |
| **PS-InSAR** | 找稳定的点目标，适合城市和岩石区 | 8 |
| **DS-InSAR** | 处理植被、裸土等低相干区 | 10 |

它**不做什么**：

- 不下载原始 Sentinel-1 SLC；
- 不做 TOPS 配准、去斜（deramp）和 burst 拼接；
- 不替代 SNAP / ISCE / Gamma / StaMPS 的生产级处理；
- 不做计量认证。

所以正确用法是：**原始 SLC 在成熟工具里预处理，InSAR Studio 负责后面的参考点、反演、出图、验证和教学。** 仓库里的两个真实案例也是按这个定位设计的。

## 1. 你需要什么

### 1.1 电脑

最低配置：

- 64 位 Windows 10/11、macOS 或 Linux；
- 4 GB 内存（真实大栈建议 16 GB 以上）；
- 2 GB 可用磁盘（演示和两个案例加起来不到 20 MB，依赖约 500 MB）；
- 能打开网页的浏览器（Chrome、Edge、Firefox、Safari 都可以）。

不需要：

- GPU；
- Docker；
- 数据库；
- 云服务器；
- 管理员权限（安装 Python 时可能需要）。

### 1.2 Python

需要 **64 位 Python 3.9–3.11**，推荐 3.11。

- Windows：从 [python.org](https://www.python.org/downloads/windows/) 下载 3.11 的 64-bit installer。安装时勾选 **“Add python.exe to PATH”**。
- macOS：从 python.org 下载，或用 Homebrew：`brew install python@3.11`。
- Linux：用系统包管理器安装 `python3.11` 和 `python3.11-venv`。

检查是否安装成功：

```bash
python --version
```

Windows 上也可能要用：

```powershell
py -3.11 --version
```

只要能看到 `Python 3.9.x` 到 `3.11.x` 即可。3.12/3.13 可以尝试，但依赖轮子可能不全，新手建议直接用 3.11。

### 1.3 网络

首次启动会安装 Python 依赖，需要能访问 PyPI。国内网络慢时可以用镜像：

```bash
python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

或者临时指定：

```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 3. 校验下载文件

校验的作用：确认文件在下载过程中没有损坏、没有被替换。对几 MB 的代码包不是必须，但对几十 MB 以上的数据包很有用。

### 3.1 先看 `.sha256` 文件里有什么

用记事本打开 `insar-studio-1.2.0.zip.sha256`，会看到一行类似：

```text
d728e9e0ae8af58f540f1c627c840eb32c66b13837b3a8e80041882b1832fc6a  insar-studio-1.2.0.zip
```

前面一长串是 SHA-256，后面是文件名。

### 3.2 Windows PowerShell

在 ZIP 所在目录打开 PowerShell（在文件夹空白处按住 Shift 右键 → “在此处打开 PowerShell 窗口”），执行：

```powershell
Get-FileHash .\insar-studio-1.2.0.zip -Algorithm SHA256
```

输出里的 `Hash` 应该和 `.sha256` 文件前面的字符串**完全一致**（不区分大小写）。

也可以一行命令比对：

```powershell
$expected = (Get-Content .\insar-studio-1.2.0.zip.sha256).Split()[0]
$actual = (Get-FileHash .\insar-studio-1.2.0.zip -Algorithm SHA256).Hash
if ($expected -eq $actual) { "OK" } else { "MISMATCH" }
```

### 3.3 macOS

```bash
shasum -a 256 insar-studio-1.2.0.zip
```

### 3.4 Linux

```bash
sha256sum insar-studio-1.2.0.zip
```

### 3.5 不一致怎么办

不要解压，重新下载。常见原因：

- 下载中断；
- 代理或镜像返回了错误页面；
- 文件被安全软件改写；
- 你比对的是旧版本的哈希。

如果重新下载仍不一致，联系维护者，不要继续安装。

## 4. 解压和放置

### 4.1 选一个简单的路径

推荐：

```text
D:\insar-studio
```

或：

```text
C:\Users\你的用户名\insar-studio
```

不推荐：

- 带中文、空格、emoji 的深层路径；
- OneDrive / 坚果云 / iCloud 同步目录（运行时会频繁读写，容易冲突）；
- `C:\Program Files`（可能需要管理员权限）；
- 路径长度超过 200 字符。

Windows 解压后，确认 `start.bat` 就在根目录，而不是多套了一层文件夹。

### 4.2 目录结构

```text
insar-studio/
├── start.bat              Windows 启动入口
├── start.sh               macOS / Linux 启动入口
├── requirements.txt       Python 依赖
├── insar_studio/          核心代码
├── docs/                  文档
├── examples/              两个真实案例
├── tests/                 自动化测试
└── workspace/             运行后生成的项目和结果（默认不提交）
```

`workspace/` 一开始可能不存在，第一次创建项目后会自动生成。

## 5. 启动

### 5.1 Windows：双击 `start.bat`

第一次启动会：

1. 找到 Python；
2. 检查依赖；
3. 如果缺依赖，自动创建 `.venv` 并安装 `requirements.txt`；
4. 启动本地 Web 服务；
5. 自动打开浏览器。

第一次安装依赖可能需要几分钟，取决于网络。以后启动会直接复用 `.venv`，几秒就能打开。

启动成功后，浏览器地址通常是：

```text
http://127.0.0.1:8765
```

如果 8765 被占用，程序会自动尝试下一个端口。终端里会打印实际地址，以终端为准。

### 5.2 macOS / Linux：运行 `start.sh`

```bash
chmod +x start.sh
./start.sh
```

如果提示没有权限，先执行 `chmod`。如果提示找不到 Python，按第 1.2 节安装 3.9–3.11。

### 5.3 手动启动（不想用脚本）

```bash
python -m pip install -r requirements.txt
python -m insar_studio serve --open
```

指定端口：

```bash
python -m insar_studio serve --port 9000 --open
```

只启动服务、不自动开浏览器：

```bash
python -m insar_studio serve --no-browser
```

### 5.4 确认环境正常

另开一个终端，在项目根目录执行：

```bash
python -m insar_studio doctor
```

它会检查 Python、依赖、工作区、写权限等。**SNAPHU 显示不可用是正常的**，本项目的默认解缠器不依赖它。

### 5.5 怎么停止

回到启动服务的终端窗口，按 `Ctrl+C`。不要直接关浏览器标签页，那只关掉了界面，服务还在后台跑。

### 5.6 启动失败怎么办

先看终端最后几行。常见原因：

- Python 没装或不在 PATH；
- 依赖安装失败（网络）；
- 端口被占用；
- 工作区没有写权限；
- 安全软件拦截了 `python.exe`。

对应解决办法见第 13 节。

| 参数 | 值 |
| --- | --- |
| 多视 `multilook` | 1 |
| 滤波 `filter` | `none` |

| 最小相干 `min_coherence` | 0.0 |
| 解缠相干阈值 `unwrap_coherence_min` | 0.0 |

| 去趋势 `remove_ramp` | 关闭 |

### 7.6 设置参考点

进入 **“反演”** 页：

- 空间参考：**手动指定**；
- 参考行 `row`：`24`；
- 参考列 `col`：`63`；
- 运行反演。

### 7.7 看结果

成果页会显示同震形变图。注意：

- 单位是 mm；
- 图上的数值被压缩了 10 倍；
- 乘 10 后峰值约 1205 mm；
- 想直接拿乘好的结果，用 `results/dingri_los_mm.tif`。

## 9. 看懂结果

### 9.1 LOS 是什么

雷达卫星斜着看地面，测到的是一维位移在**视线方向**（Line of Sight，LOS）的投影。它不是垂直升降，也不是水平位移。

- 正值：地表朝卫星方向移动（靠近卫星）；
- 负值：地表远离卫星；
- 0：参考点或没有形变。

同一个真实的三维位移，在升轨和降轨影像上可能呈现不同的正负和大小。不要看到红色就说“抬升”。

### 9.2 参考点是什么

D-InSAR 和时序 InSAR 得到的都是**相对位移**。必须选一个像元作为 0 基准，其他像元相对它计算。

- 自动参考点：算法选相干性高、时序稳定的像元；
- 手动参考点：你自己指定行、列。

参考点选在形变区里，会把真实形变扣掉一部分；选在噪声上，会把噪声带进整张图。教学案例都给了验证过的参考点。

### 9.3 速率图怎么读

- 单位 `mm/yr`；
- 颜色只表示 LOS 方向；
- 掩膜外是空白，不是 0；
- 要看空间形态，不要只盯一个最大值；
- 速率依赖时间轴，时间轴不可信时，速率只能做相对比较。

### 9.4 相干性怎么读

相干性 0–1，越高越可信。植被、水体、施工区通常低；岩石、建筑、裸土通常高。低相干区解缠容易出错，结果会出现随机斑块。

### 9.5 图上的空白是什么

通常是：

- 掩膜排除的边缘；
- 无数据像元；
- 低相干被阈值剔除；
- NaN。

空白不代表位移为 0。

### 9.6 成果包 ZIP 里有什么

点击 **“下载成果包 ZIP”** 会打包：

- 产品数组（`.npy`）；
- GeoTIFF；
- PNG 图件；
- 报告；
- 项目配置。

适合归档和发给别人。注意：ZIP 里可能包含绝对路径或项目元数据，外发前检查一下。

### 9.7 报告

点击 **“生成报告”** 会生成一份包含参数、统计和图的文档。它适合内部记录，不是论文级质量报告。

## 10. 导入自己的数据

### 10.1 支持什么

工作台支持：

- 复数 `.npy` 栈，形状 `(dates, rows, cols)`；
- `.npz` 包，含 `slc`，可选 `dem` / `mask` / `dates`；
- 原生目录，含 `slc.npy`、可选 `dem.npy` / `mask.npy`、`meta.json`；
- ENVI、GeoTIFF、SAFE 等格式的有限读取；
- 已经配准好的 SLC 栈。

不支持：

- 原始 TOPS SLC 的直接配准、去斜、burst 拼接；
- 未配准的 Sentinel-1 SAFE 直接当时序栈用。

### 10.2 原生目录最小结构

```text
my_stack/
├── slc.npy          # complex64，形状 (n_dates, rows, cols)
├── dem.npy          # float32，形状 (rows, cols)，可选
├── mask.npy         # bool，形状 (rows, cols)，可选
└── meta.json        # 元数据
```

`meta.json` 最小示例：

```json
{
  "schema": "insar-studio/stack/v1",
  "name": "my stack",
  "rows": 500,
  "cols": 500,
  "n_dates": 12,
  "dates": ["2024-01-01", "2024-01-13"],
  "wavelength_m": 0.055465763,
  "incidence_deg": 38.0,
  "range_spacing_m": 2.329562,
  "azimuth_spacing_m": 13.9,
  "already_coregistered": true
}
```

如果要输出地理坐标 GeoTIFF，还需要：

```json
{
  "corner_lon": 98.69603,
  "corner_lat": 31.08736,
  "lon_step": 0.000185,
  "lat_step": -0.000185,
  "crs": "EPSG:4326",
  "geo_referenced": true,
  "start_times": ["2024-01-01T00:00:00", "2024-01-13T00:00:00"],
  "slant_range_m": 705000.0
}
```

更完整的字段说明见 [使用指南](使用指南.md) 第 3.3 节。

### 10.3 导入前预检

界面里的 **“预检并导入”** 会先做只读检查，显示：

- 景数；
- 尺寸；
- 地理参考；
- 验证级别（`full` / `sampled` / `header`）；
- 全部警告。

确认无误后再覆盖当前栈。预检不会修改数据。

### 10.4 最少景数

| 路线 | 最少景数 |
| --- | ---: |
| D-InSAR | 2 |
| SBAS | 8 |
| PS | 8 |
| DS | 10 |

不足时，导入、切换路线和启动全流程都会在开始前被拒绝。这是为了避免跑一半才失败。

### 10.5 缺少元数据会怎样

- 缺 `bperp_m`：垂直基线置零，DEM 误差估计不可用；
- 缺 `dates`：按 12 天间隔补齐，标记为 `inferred`；
- 缺 `corner_lon` / `corner_lat`：成果使用像元坐标，不输出地理 GeoTIFF；
- 缺 `start_times` / `slant_range_m`：地理编码可能显示 `unavailable`。

导入后务必核对日期顺序、尺寸和警告。

### 12.2 改工作区位置

设置环境变量 `INSAR_STUDIO_WORKSPACE`：

Windows PowerShell：

```powershell
$env:INSAR_STUDIO_WORKSPACE = "D:\insar-projects"
python -m insar_studio serve --open
```

macOS / Linux：

```bash
export INSAR_STUDIO_WORKSPACE=/data/insar-projects
```

- 整个 `workspace/projects/<项目ID>` 目录复制走即可；

### 12.4 删除项目

界面上删除，或直接删 `workspace/projects/<项目ID>`。删除前确认里面没有你要的结果。

## 13. 常见问题

### Q1：`python` 不是内部或外部命令

Python 没装，或者没加到 PATH。

- 重新安装 Python，勾选 “Add python.exe to PATH”；
- 或者用 `py -3.11` 代替 `python`；
- 或者双击 `start.bat`，它会自动找常见安装位置。

### Q2：双击 `start.bat` 后窗口一闪就没了

在文件夹空白处按住 Shift 右键，选“在此处打开 PowerShell 窗口”，然后执行：

```powershell
.\start.bat
```

这样窗口不会自动关闭，能看到错误信息。

### Q3：依赖安装很慢或失败

换镜像：

```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

或者设置全局镜像后重试。公司网络可能需要代理。

### Q4：端口 8765 被占用

默认会自动尝试下一个端口，看终端打印的地址。想固定端口：

```bash
python -m insar_studio serve --port 9000 --open
```

### Q5：浏览器没有自动打开

手动打开终端里显示的地址，通常是 `http://127.0.0.1:8765`。如果还是打不开，检查服务是否还在运行。

### Q6：页面空白或 404

- 确认地址是 `http://127.0.0.1:8765`，不是 `https`；
- 强制刷新（Ctrl+F5）；
- 看终端有没有报错；
- 删除浏览器缓存或换一个浏览器。

### Q7：终端中文乱码

Windows 终端编码问题。`start.bat` 已经设置 UTF-8；如果手动启动，先执行：

```powershell
chcp 65001
```

### Q8：导入时报“找不到 SLC”

检查目录里是否有 `slc.npy`，或者 `meta.json` 里的 `slc_path` 是否指向真实文件。原生目录最小结构见第 10.2 节。

### Q9：导入时报“至少需要 N 景影像”

当前路线的最少景数不够。D-InSAR 要 2 景，SBAS/PS 要 8 景，DS 要 10 景。换路线或补数据。

### Q10：日期不对，或者显示“推断”

`meta.json` 没提供 `dates`，工作台按 12 天间隔补齐，并标记为 `inferred`。真实数据务必自己提供日期。

### Q11：提示缺少 `bperp_m`

垂直基线缺失。工作台会把基线置零，DEM 误差估计不可用，但 D-InSAR 和部分时序仍能跑。要精确处理，请从原始轨道或元数据补 `bperp_m`。

### Q12：成果没有地理坐标

缺少 `corner_lon` / `corner_lat` / `lon_step` / `lat_step`，或者缺少 `start_times` / `slant_range_m`。工作台会保留雷达网格，`products/geocode.json` 会写 `unavailable` 和原因。

### Q13：结果全是 NaN 或空白

常见原因：

- 掩膜把所有像元排除了；
- 相干性阈值太高；
- 解缠失败；
- 参考点落在无效像元；
- 输入相位全是 0。

先看干涉页的相干性图和有效像元比例，再调低 `min_coherence` / `unwrap_coherence_min`。

### Q14：解缠很慢或内存不够

- 增大 `multilook`；
- 减少干涉对；
- 关闭其他程序；
- 大栈建议 16 GB 以上内存；
- 不要把 4000 × 4000 的栈当教学数据跑。

### Q15：结果和示例不完全一样

检查：

- Python / NumPy / SciPy 版本；
- 参数是否完全一致；
- 参考点是否一致；
- 是否重新生成了网络。

解缠器在不同版本间可能有微小数值差异。

### Q16：怎么更新

git clone 的用户：

```bash
git pull
```

ZIP 用户：重新下载并解压，保留旧的 `workspace/`，把新代码目录指向旧工作区即可。

### Q17：怎么卸载

删除项目目录即可。Python 依赖装在 `.venv` 里，跟着目录一起删。系统 Python 不受影响。

### Q18：仓库私有，打不开

让维护者把你的 GitHub 账号加入协作者，或者使用维护者提供的发布包。

### Q19：安全软件报毒

Python 脚本和本地 Web 服务偶尔会被误报。确认文件来自官方仓库，校验 SHA-256 后再决定是否放行。不要从陌生网盘下载修改版。

### Q20：能不能处理商业数据

可以，只要导出的格式符合第 10 节。注意数据许可和保密要求，不要把敏感数据提交到公开仓库。

## 14. 术语表

| 术语 | 解释 |
| --- | --- |
| **InSAR** | 合成孔径雷达干涉测量，用两景雷达相位差测形变 |
| **SLC** | 单视复数影像，保留相位和振幅 |
| **DEM** | 数字高程模型 |
| **LOS** | 视线方向，雷达看到的一维投影 |
| **干涉对** | 两景影像组合，形成一张干涉图 |
| **相干性** | 0–1，衡量两景相位的一致程度 |
| **解缠** | 把缠绕在 ±π 的相位恢复成连续相位 |
| **基线** | 两景轨道之间的空间/时间间隔 |
| **参考点** | 位移为 0 的基准像元 |
| **APS** | 大气相位屏，大气延迟造成的相位误差 |
| **SBAS** | 小基线集，多景短基线组合的时序方法 |
| **PS** | 永久散射体，稳定的点目标 |
| **DS** | 分布式散射体，面状低相干目标 |
| **D-InSAR** | 差分干涉，单对影像的形变测量 |
| **回放栈** | 用公开产品反推构造的、工作台可读的 SLC 栈，不是原始 SLC |
